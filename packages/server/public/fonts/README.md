Google Fonts, licensed under the SIL Open Font License 1.1. The licence
texts sit next to the files, as the OFL requires.

| Family | Copyright | Licence |
|---|---|---|
| Golos Text | 2019 The Golos Text Project Authors | [OFL-GolosText.txt](OFL-GolosText.txt) |
| PT Mono | 2011 ParaType Ltd. — Reserved Font Names "PT Sans", "PT Serif", "PT Mono", "ParaType" | [OFL-PTMono.txt](OFL-PTMono.txt) |

The subsets are the ones Google Fonts serves and are not renamed; they
are used here only as web fonts for the console and the install page.
