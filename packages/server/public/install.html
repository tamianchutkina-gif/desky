Desky Install on this Mac

One line, and Desky is installed.

Copy the line below, paste it into Terminal, and press Return. It downloads Desky, installs it, and starts it. Nothing is shared and nobody can see your screen until you press Allow yourself.

curl -fsSL __DESKY_ORIGIN__/install.sh | bash
  1. Open Terminal Press ⌘ Space, type Terminal, press Return.
  2. Paste the line and press Return It takes a minute or two. Leave the window open until it finishes.
  3. Grant Screen Recording when asked Desky opens the right pane of System Settings for you. Without it there is nothing to share.
  4. Read out the computer number Nine digits, shown in the Desky window. Then wait — a request appears, and you decide.

Why a command and not a normal download. Desky is not distributed through the App Store and carries no paid Apple developer certificate, so a copy downloaded in a browser is blocked by macOS with no way past it. Fetched this way it is not, which is the only reason for the extra step.

What it does to your Mac. It writes one application to your Applications folder and starts it. Nothing else is installed and nothing runs in the background afterwards. Quitting Desky ends any session immediately.
